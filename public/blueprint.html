The 6 Non-Negotiable Architectural Rules

Strict tenets enforced on every code modification across all conversations

01

Anti-N+1 Query Policy

Strict lazy loading forbidden via Model::preventLazyLoading(). Every relationship retrieval must explicitly use with(['relation']).

02

Action / Service Layer (No Fat Controllers)

Controllers only validate inputs, call actions, and return responses. Domain mutations live exclusively in app/Actions/ and app/Services/.

03

Atomic DB Transactions

Operations touching multiple tables (Stock-in, Checkout, Cancellations) are wrapped in DB::transaction(fn(), 5) with dead-lock retry protection.

04

Real COGS Profit Tracking

Order items snapshot immutable purchase unit cost price at purchase time, guaranteeing real mathematical Gross Profit calculation: (Subtotal - Discount) - Σ(Cost × Qty)

05

Zero Hardcoding (100% Dynamic)

No hardcoded logos, phone numbers, emails, currency symbols, or sliders. Every asset is managed through Admin Settings CMS, cached in Redis, and shared globally.

06

Standardized Directory Layout

Strict separation into Actions/, Services/, Models/, and React atomic components under resources/js/Pages/ and Layouts/.
